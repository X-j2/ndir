## 0. 修订摘要

1. **突发丢点**：短窗口与整病例使用不同缺口生成规则；短窗口缺口必须完整落在
   窗口内，窗口不足时不插入；整病例按每分钟节拍生成并显式处理尾段不足。
   保存实际缺口起止、长度、seed、新增缺失比例，不能只保存名义参数。
2. **特征消融人群**：改为明确的 **RF-only** 口径：训练和评价都只使用
   `quality_state == VALID` 且真值属于 U0/U1/U2 的同一批行；所有特征组使用
   完全相同的外层病例划分和评价行。
3. **四尺度主机一致性**：使用开发集超过 90 s 的时间线，独立构建离线参考，
   比较四尺度决策时间、窗口范围、历史可用性、质量、特征、概率、融合帧和
   事件转换；另量化 100 Hz 原始输入 vs 25 Hz 降采样/主机重采样的差异。
4. **命名**：把旧“无迟滞”准确改名为“移除持续计数，保留双阈值迟滞”；
   counts=1 仍保留进入/退出双阈值。
5. **band_ratio 稳定性判据**：只使用正增益/偏置条件的 Spearman ρ 和中位
   相对变化；噪声/Gamma/削顶等其他扰动单独报告，不得替代增益/偏置条件。

本轮不修改模型、质量、融合或事件算法；若实施中发现必须修改，先升版本并
重跑所有受影响基线和收益判定。

## 1. 突发丢点修订

### 1.1 短窗口模式

对长度为 `L` 的短窗口（窗级实验，15 s = 1500 点 @100 Hz）：

- 请求缺口长度 `n = round(level_sec * FS)`；
- 若 `L >= n`：随机起点必须满足
  `start ∈ [0, L - n]`，缺口为半开区间 `[start, start+n)`；
  **不得越界后压到末尾或压缩成单点**；
- 若 `L < n`：**不插入缺口**，记录
  `status="insufficient_window"`、`actual_gap_samples=0`；
- 原有 NaN 保留；只记录**新增**缺失样点，不把原有 NaN 当作新增；
- 每个 seed 决定起点；同一 seed 可复现。

### 1.2 整病例模式

对完整病例按“每分钟一个缺口”的预注册节拍生成：

- 节拍位置 `base = 0, 60*FS, 120*FS, ...`；
- 每个节拍在 `[base, base + 60*FS - n]` 内随机抖动生成起点，要求完整缺口
  落在病例内；
- 尾段若 `base + n > L`：**跳过该尾段缺口**，记录
  `tail_skipped=True`，不把缺口压到病例末尾；
- 原有 NaN 保留；不删除样点、不压缩时间轴；
- 记录每个实际缺口起止、长度、seed、新增缺失比例和跳过尾段数。

### 1.3 审计与测试

- 对 1500 点且完全有限的窗口，seed 0–4：
  - 0.2 s → 连续 **20** 点；
  - 1 s → 连续 **100** 点；
  - 5 s → 连续 **500** 点；
  - 每个缺口满足 `start >= 0` 且 `start+n <= 1500`；
- 补充窗口不足、已有 NaN、尾段不足测试；
- 窗口级结果固定干净 VALID 质量，只解释特征/模型稳定性；不得据此宣称
  质量层能吸收 5 s 长缺口；
- 重跑窗口级 burst_drop 并撤回旧的“5 s 丢点几乎无影响”结论（若实际结果
  仍无影响，必须解释实际插入长度，不得用错误缺口长度）。

## 2. 特征消融 RF-only 口径

### 2.1 人群

对 U15/U30 分别：

```
eval_mask = (quality_state == VALID) AND (truth_label ∈ {U0,U1,U2})
```

- 训练行和评价行使用同一 `eval_mask`；
- 外层 5 折病例划分固定，所有特征组完全相同；
- 不把平坦候选、UNKNOWN、U3、ignore、unlabeled 送进 RF；
- 不经过完整规则分流；本表不声称代表完整流水线；
- 固定权重 `u2x10`，不做校准/阈值选择，不按外层结果调参。

### 2.2 报告

每个特征组报告：

- 评价病例数、评价行数、U0/U1/U2 支持数；
- Macro-F1；
- U2 Precision / Recall / F1。

必须对比旧消融表人群差别并说明数字变化来源。若另报完整流水线消融，必须
保留规则分流和 UNKNOWN 处理，单独成表，不得与 RF-only 混写。

### 2.3 本阶段特征组

全 15 维、去 `band_ratio`、去 `acf_peak`、去 `flat_run_frac`、去三者。

## 3. 四尺度主机一致性

### 3.1 时间线与参考

- 使用开发集病例，时间线 **>90 s**；U15/U30/U60/U90 均实际产生决策；
- 同一 25 Hz 输入时间线；
- 离线参考从原始 100 Hz 数据、冻结特征/质量/校准/事件参数独立构建；
- **不得**直接使用 runtime 的 `history`、`_series`、`last_features` 或
  runtime 内部缓存作为参考答案；
- 两条路径统一：会话起点、预热历史、sample time base、窗口端点取整、
  缺口/UNKNOWN 位置；
- 比较：
  - 决策时间；
  - 窗口起止/范围；
  - 历史可用性（known/ever/recent、past_sec、A_ref/peaks）；
  - 质量状态；
  - 15 维特征；
  - 校准 U2 概率；
  - 融合帧；
  - 事件转换（kind/time/episode 关键字段）。
- 浮点特征/概率用明确容差；状态/决策时间/窗口范围/事件转换要求精确一致。
- 同一实现重复调用只作为自洽检查，不能作为独立一致性证明。

### 3.2 100 Hz vs 25 Hz

另在相同原始时间线上：

- 原始 100 Hz 参考；
- 100 Hz → 25 Hz 降采样 → 主机重采样到 100 Hz 路径；
- 分别报告各尺度特征差、质量状态变化、概率变化、事件/融合变化；
- 真实重采样差异可保留，但必须量化并解释，不得声称无条件完全一致。

### 3.3 场景

至少包含：

- 缺口/UNKNOWN；
- 真实事件或平坦段；
- 1×/2×、暂停、跳转、长跑；
- 四尺度决策覆盖；
- 生产库/通知隔离。

## 4. 命名与 band_ratio 判据

### 4.1 时序消融命名

旧“无迟滞”只将 counts 设为 1，仍保留 `active_enter/active_exit` 双阈值。
本轮统一命名为：

> **移除持续计数，保留双阈值迟滞**

表格、JSON key 和结论必须使用该名称；本轮不新增“无双阈值”实验。

### 4.2 band_ratio 稳定性

预注册判据仅使用：

- 正增益 0.5×、2× 的 Spearman ρ；
- 偏置 ±0.5A 的 Spearman ρ；
- 上述四个条件的**中位相对变化**。

```
rho_gain = min(rho_gain_0.5, rho_gain_2)
rho_bias = min(rho_bias_+0.5, rho_bias_-0.5)
median_gb = max(median_rel(gain_0.5), median_rel(gain_2),
                median_rel(bias_+0.5), median_rel(bias_-0.5))
stable = rho_gain >= 0.8 and rho_bias >= 0.8 and median_gb <= 0.20
```

噪声、随机/突发丢点、滞后、漂移、Gamma、削顶、负增益、量化的稳定性
单独报告；不得用其中的最大中位相对变化替代增益/偏置条件。

增加单元测试：

- 增益/偏置满足 ρ 且中位变化 ≤0.20，即使噪声/Gamma 变化很大，仍判稳定；
- 增益/偏置中位变化 >0.20 判不稳定；
- ρ<0.8 判不稳定。
