## 0. 边界与不可变约束

1. Final Test 只读取病例号做互斥检查，不加载波形、标签、事件或概率。
2. 不改 Keil 固件、不做气体标定；不写入设备实时 C 模式。
3. 相对模式、旧告警隔离、C 模式禁用继续有效。
4. 所有模型、校准器、融合参数、状态机参数、阈值只在开发集病例级内层
   （outer-training 的 inner CV）选择；外层测试折不参与任何拟合或选择。
5. “最佳单尺度”必须在内层选择，不能先看外层结果再挑尺度。
6. 没有稳定收益的融合方案不接入默认路径，只保留实验选项；负结果如实报告。
7. 事件名仍为“呼气 CO₂ 低值/消失样事件”，不宣称临床确诊屏息。

## 2. 单尺度模型、校准与事件引擎

### 2.1 模型

- 每个尺度一个 RF：30 树、`max_depth=8`、`random_state=42`；
- 训练行：`label ∈ {U0,U1,U2}` 且 `quality_state == VALID`；
- 类别权重候选沿用 Stage 2/3：`none/u2x3/u2x10/u2x30/balanced`；
- 校准候选沿用 Stage 2 v2：`none/temperature/multinomial_logistic`；
- U15/U30 沿用既有配置；U60/U90 按相同流程训练。

### 2.2 嵌套选择

- 外层 5 折病例级、事件分层；
- 每折外层训练集内做 3 折病例级 inner CV；
- inner CV 选择：类别权重 → 校准器（leave-one-inner-fold-out log loss）→
  Stage 3 事件参数；
- 外层测试折只应用，不参与选择；
- U15/U30/U60/U90 共用同一病例折分配（以 U15 事件表构造的折为准），
  保证融合比较时病例对齐。

### 2.3 单尺度事件引擎

- 沿用 `stage3_event_engine_spec_v2`：严格连续计数、缺失决策 deadline
  中断、UNKNOWN 清空、FLAT_EVER 只 SUSPECT、转换快照；
- 参数网格沿用 Stage 3：108 组；
- 事件指标沿用 Stage 2 v2 的可评分裁剪、一对一匹配、TTD、FA/h、
  告警持续占比、UNKNOWN 比例；
- U60/U90 与 U15/U30 使用完全相同的评价口径。

## 3. 多尺度融合

### 3.1 允许的证据

每个尺度只在窗口结束后产生一个决策：

```
decision_time = window end
quality_state ∈ Stage 1 v3 states
p_u2 = calibrated U2 probability (only VALID)
```

- 禁止使用窗口 `start` 或未来样本；
- 禁止把相邻重叠窗口当作独立证据连乘、无限累加或无界 log-odds 累积；
- 每个尺度在同一融合 tick 最多贡献一个“最新决策”。

### 3.2 融合网格与有效期

- 融合 tick：7.5 s（U15 步长；U30/U60/U90 步长均为 7.5 的整数倍）；
- 每个尺度 `s` 的最新决策在 `[decision_time, decision_time + step_s)`
  有效；
- 在融合 tick `t`，只有 `decision_time <= t` 且
  `t - decision_time < step_s - tol` 的决策可参与；
- 超过有效期（缺失决策/数据中断）即视为该尺度无证据；不沿用旧值；
- 若所有尺度都无有效证据 → 融合质量状态 `GAP`，事件引擎按 UNKNOWN 处理；
- UNKNOWN **不当作正常，也不当作负证据**。

### 3.3 投票、权重与去重

- 每个有效尺度每个 tick 一票；
- 权重档案（预注册四组，均归一化）：
  - `balanced`：U15 0.5 / U30 0.8 / U60 1.0 / U90 1.2；
  - `equal`：四尺度均为 1.0；
  - `early`：U15 1.2 / U30 0.8 / U60 0.5 / U90 0.3；
  - `confirm`：U15 0.4 / U30 0.8 / U60 1.0 / U90 1.2；
- 证据值：
  - `VALID`：`v_s = p_u2`；高置信来源；
  - `FLAT_WITH_HISTORY`：`v_s = 1.0`；高置信来源；
  - `FLAT_EVER_HISTORY`：`v_s = 1.0`，权重乘 0.5；**不算高置信来源**；
  - 其他 UNKNOWN 状态：无票；
- 时间衰减：`decay = exp(-age / tau)`，`age = t - decision_time`；
- 融合分数：

```
score = sum_s(weight_s * decay_s * v_s) / sum_s(weight_s * decay_s)
```

  只用有效票；结果天然在 `[0,1]`，不是概率乘法或无限累加；
- 不把重复窗口/重叠窗口再次计票；同一尺度在一 tick 只有最新一票；
- `FLAT_EVER_HISTORY` 只能产生 SUSPECT：若所有有效票均来自低置信来源，
  融合状态置 `FLAT_EVER_HISTORY`；
- 若高置信来源数 < `min_active_sources`，融合分数封顶在
  `active_enter_p - 1e-6`，不得触发 ACTIVE；
- 若至少一个高置信来源且高置信来源数满足门槛，融合状态 `VALID`，分数
  进入 Stage 3 事件引擎。

### 3.4 融合参数与内层选择

预注册融合候选：

| 参数 | 候选 |
|---|---|
| 权重档案 | balanced / equal / early / confirm |
| 衰减常数 `tau` | 30 / 60 / 120 s |
| `min_active_sources` | 1 / 2 |
| 融合 tick | 固定 7.5 s |
| 事件参数 | Stage 3 的 108 组网格 |

为避免组合爆炸，采用**冻结的两阶段内层选择**：

1. 固定参考事件参数
   `suspect_p=.10, active_enter=.30, active_exit=.10, suspect 1/1, active 2/2`，
   在内层 OOF 上选权重档案/tau/min_active_sources（24 组）；
2. 固定上一步权重，在内层 OOF 上选 108 组事件参数；
3. 外层测试折只应用两步选出的参数。

两阶段的选择顺序和候选集在本规范中冻结；不得看完外层结果再改。

### 3.5 保留 Stage 3 语义

- 融合 tick 的 `(t, quality_state, fused_p)` 直接送入未修改的 `EventEngine`；
- 严格连续进入/退出、缺失决策中断、UNKNOWN 清空、低置信限制、转换快照
  全部保留；
- 融合输出的事件仍是“呼气 CO₂ 低值/消失样事件”。

## 4. 同口径比较与收益判据

### 4.1 比较方法

同一外层 OOF、同一 303/60 事件、同一可评分时域：

1. **B0 规则基线**：Stage 1 B0 的 U2 决策，Stage 2 v2 原始告警代理；
   无概率阈值；
2. **Stage3 方案**：U15 与 U30 各自独立的 Stage 3 单尺度事件引擎
   （已审查方案；U15 为现有默认主尺度，U30 为独立第二尺度）；
3. **最佳单尺度**：每个外层折在内层按 ACTIVE event F1（其次 recall、
   较低 FA/h、尺度顺序）从 U15/U30/U60/U90 中选一个；外层只应用；
4. **融合方案**：§3 的四尺度共识 + Stage 3 事件引擎。

B0 是无状态原始代理，与状态机方法的差异必须在表格/脚注中说明；不把
B0 的 U3 预测当 FP。

### 4.2 指标

每个方法报：

- TP/FN/FP、Recall、PPV、F1；
- 可评分 FA/h、告警持续占比；
- UNKNOWN 决策比例/UNKNOWN 终止事件数；
- TTD 中位、非负 TTD 中位、早期预警数、30/60/90 s 检出率；
- 无窗口事件 FN；
- case-cluster bootstrap 95% CI。

### 4.3 配对差值

对融合 vs 最佳单尺度（以及融合 vs U15、融合 vs U30）做**配对病例级
bootstrap**：

- 1000 次，按病例有放回重采样；
- 同一次重采样同时计算两个方法，得到差值；
- 报 Recall/PPV/F1/FA/h/告警持续占比 的差值点估计与 95% CI；
- 百分比与百分点分开写：例如“F1 +5.0 个百分点（不是 +5%）”。

### 4.4 收益判据（实施前冻结）

融合相对**内层选出的最佳单尺度**必须同时满足：

1. ACTIVE event F1 提升 **≥ 5.0 个百分点**；
2. 可评分 FA/h 不恶化超过 **10%**（融合 FA/h ≤ 1.10 × 最佳单尺度）；
3. Recall 不下降超过 **5.0 个百分点**；
4. 配对病例级 bootstrap 的 F1 差值 95% CI 下界 **> 0**。

任一条不满足：

- 记录为负结果；
- 不接入上位机默认路径；
- 默认保留最佳单尺度/已审查 Stage3 方案，融合仅作实验选项；
- 不因负结果调整判据或重新挑外层结果。

## 5. 鲁棒性与扰动

### 5.1 原则

- 只改变 CO₂ 波形/输入链路，不篡改参考真值、标签、事件或可评分时域；
- 时间轴保持绝对样本索引；丢点用 NaN 表示，不删除样点后压缩时间；
- 长缺口使窗口缺失/UNKNOWN，事件仍按原真值计 FN；
- 每个随机扰动固定 seed；保存配置和 seed；
- 所有结果标记“算法级模拟”，不是硬件验证，也不声称协议能检测所有丢帧。

### 5.2 扰动族

| 族 | 水平 |
|---|---|
| 正增益 | 0.2 / 0.5 / 1 / 2 / 5 |
| 偏置 | −0.5A / −0.2A / 0 / +0.2A / +0.5A |
| 高斯噪声 | 0 / 0.5 / 1 / 2 / 5 mmHg（VitalDB 模拟单位） |
| 随机丢点 | 0 / 1 / 5 / 10 %（NaN，保留时间轴） |
| 突发丢点 | 0.2 / 1 / 5 s 连续 NaN |
| 一阶响应滞后 | 0 / 0.5 / 1 / 2 s |
| 漂移 | 0 / 0.1 / 0.5 A/min |
| Gamma 非线性 | 0.5 / 0.8 / 1.0 / 1.25 / 2.0 |
| 削顶/饱和 | 按病例 q1/q99 截断 |
| 负增益 | a=-1（极性检测/弃权测试） |
| 量化 | 8 / 10 / 12 / 16 bit |

- Gamma 对负 z 使用保号的 `sign(z)*abs(z)^gamma`，保持单调、不产生 NaN；
- 削顶使用病例级 q1/q99，保持长度不变；
- 丢点/突发丢点后重新走窗口/质量/UNKNOWN 路径，不手工补真值。

### 5.3 评价范围

- **窗口级全网格**：从开发集固定抽样 10,000 个干净 VALID 窗口（seed 42，
  按 U0/U1/U2 分层，不按结果挑选），应用全部扰动族/水平；
  报模型一致率、Macro-F1、U2 F1、覆盖率/弃权率；该层只测特征/模型稳定性，
  质量状态固定为干净 VALID（不冒充质量鲁棒性）。
- **事件级压力集**：对通过外层 OOF 选出的最终方案（融合若未通过判据则
  最佳单尺度），在完整 200 例/303 事件上重算以下压力条件：
  - 干净；
  - 正增益 0.5×、2×；
  - 偏置 +0.5A、−0.5A；
  - 噪声 2 mmHg（5 seeds）；
  - 随机丢点 5%（5 seeds）；
  - Gamma 1.25；
  - q1/q99 削顶；
  - 一阶滞后 2 s；
  - 漂移 0.5A/min；
  - 负增益 −1。
- 事件级压力集使用外层折内层选择的模型/参数；不重新调参；
- 报事件 Recall/PPV/F1/FA/h/UNKNOWN/弃权率相对干净的变化；
- 随机扰动使用 5 seeds，报均值与最坏条件；
- 正增益/偏置的 SI 不变性另做 5,000 窗特征核对（特征差 <1e-6 视为通过），
  仍报告质量/覆盖变化。

### 5.4 正增益/偏置的解释边界

- 正仿射不变性只在有效、未截断动态范围内成立；
- 报告有效窗口覆盖率和弃权率，不只报已出预测的一致率；
- 负增益、Gamma、饱和、滞后不满足正仿射不变性，必须实测。

## 6. 消融

### 6.1 新增尺度

- 四尺度融合 vs U15/U30 两尺度融合（相同权重档案/参数中去除 U60/U90）；
- 四尺度融合 vs 最佳单尺度；
- 明确 U60/U90 是否带来稳定收益；无收益则保留为证据源/实验项。

### 6.2 融合与去重

- 主融合（归一化加权共识）vs 朴素 log-odds 累加（会重复计数）；
- 主融合 vs 无时间衰减（tau→∞）；
- 相同评价病例、相同事件参数/阈值（若参数不可直接复用，在内层重选并
  报告）；
- 报事件 F1、FA/h、告警持续占比。

### 6.3 时序机制

- 完整 Stage 3 状态机（严格连续计数 + 缺失中断 + 迟滞）vs 无迟滞
  （counts=1/1/1/1，保留 UNKNOWN/快照）；
- 报事件 F1、FA/h、UNKNOWN、报警负担。

### 6.4 关键新增特征

- 在 U15/U30 外层 5 折、固定 `u2x10` 权重的窗级消融：
  - 全 15 维；
  - 去 `band_ratio`；
  - 去 `acf_peak`；
  - 去 `flat_run_frac`；
  - 去三者组合；
- 报 Macro-F1、U2 F1、覆盖率；不参与主事件指标选择；
- **15 s `band_ratio` 稳定性**：在固定窗口样本上计算干净 vs 正增益/偏置/
  噪声/丢点/Gamma/削顶后的 Spearman ρ 与中位相对变化；
  预注册判据：正增益/偏置下 ρ≥0.8 且中位相对变化≤0.20 视为稳定；
  若不稳定，报告“建议未来从 U15 移除”，本阶段不静默改特征；如实际移除，
  必须升规范版本并重跑 U15 及所有受影响基线。

## 7. 上位机接续

### 7.1 默认路径

- 融合未通过 §4.4 判据：默认路径保持已审查 Stage3 U15/U30；融合只出现在
  隔离回放的“实验”选项；
- 融合通过：才允许把融合加入默认路径；仍需相对模式、旧告警隔离和 C 模式
  禁用。

### 7.2 实验 runtime

- 新增 `Stage4Runtime`（四尺度 + 融合）作为**实验 runtime**，不替换默认
  Stage3 runtime；
- 复用相同特征/质量/校准/事件引擎实现；
- 融合按 §3 的 7.5 s 网格、有效期、权重、去重和 UNKNOWN 规则；
- 不写生产 DB、不触发生产通知/蜂鸣、不控制串口、不影响实时会话。

### 7.3 一致性验证

- 用同一 25 Hz dev replay 时间线，比较离线算法与 `Stage4Runtime`：
  - 特征向量（容差 1e-6 或报告明确差异）；
  - 质量状态（精确一致）；
  - 校准后 U2 概率（容差 1e-6）；
  - 融合事件/状态（精确一致或报告明确差异）；
- 明确记录 25 Hz→100 Hz 重采样与离线 100 Hz 输入的差异；
- 不允许用“同一实现两次运行”冒充独立验证。

### 7.4 运行与隔离测试

- 长时间运行（至少 10 分钟 signal time）不崩溃、状态有限、无泄漏；
- 变速回放（1×/2×）、暂停/继续、跳转/重启：相同 signal time 下 states/events
  一致；
- 串口重连/数据中断：新增尺度清空窗口/历史/事件计数，旧输出按预期 deadline
  结束并落库；
- 回放前后生产 DB 行数、告警、事件记录、通知不变；
- 相对模式、旧固件四分类不触发旧告警、C 模式请求被拒绝继续通过。

## 8. 验收与产物

### 8.1 验收测试

1. U60/U90 缓存/事件计数/指纹正确；
2. 四尺度单尺度结果使用相同 303/60 事件和可评分时域；
3. 融合 tick 只使用 `decision_time <= t` 的证据；无未来证据；
4. 一尺度一 tick 一票；有效期外证据不参与；全无证据 → UNKNOWN；
5. FLAT_EVER 不能单独 ACTIVE；低置信票不能绕过 min_active_sources；
6. 融合沿用 Stage 3 严格连续计数/缺失中断/快照；
7. 内层选出的最佳单尺度不看外层结果；
8. 融合收益判据和配对 bootstrap 自动计算；未通过时明确负结果；
9. 扰动保留时间轴/真值；丢点产生缺失/UNKNOWN，不压缩时间；
10. 消融组可复现；band_ratio 稳定性判据自动执行；
11. Stage4Runtime 与离线在相同时间线的一致性/差异有测试；
12. 回放/会话隔离、相对模式、旧告警切断、C 模式禁用回归通过。
