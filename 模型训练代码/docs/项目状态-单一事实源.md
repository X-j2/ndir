## 5. 未解决风险

1. **U2 语义**：EtCO₂<10 可能是呼吸暂停、漏气、脱管、采样管故障；没有独立气流/呼吸努力，不能写“临床确诊屏息”。
2. **域偏移**：VitalDB 是术中机械通气；样机是自主呼吸。
3. **设备数据不可用**：不能做设备精度/实时验证；所有演示标 Replay/public data。
4. **标定/协议**：固件无标定 flag、无帧序号；实时 C 模式禁用；实时链路丢帧不可检测。
5. **平坦 vs 断线/饱和**：Stage 1 已实现 GAP / SATURATED / FLAT_* / UNKNOWN，但 VitalDB 无设备 rail、无真实拔管事件；SATURATED 仅合成验证，恒零且无历史只能 UNKNOWN。`q90-q10=0` 但有限样本仍有变化的窗判 `QUANTILE_ARTIFACT`/UNKNOWN，只有真正常数窗保留平坦候选路径。
6. **噪声估计**：MAD(diff) 在平台上退化为 0；Stage 1 质量层改用 `noise_ratio_hf`（2Hz 残差 / A），阈值 0.25 仍为开发集暂定值。
7. **Final Test 事件数**：U2 可靠 73/35、低支撑 15/13、RR<3 18/15；可靠事件仍偏少，CI 会宽；低支撑事件不判正/负。
8. **论文/实物两套叙事**：旧指标只属于旧模型；新 U15/U30 数字只属于开发集单尺度模型，不能借用旧 4 类/12 维/90s 指标。
9. **B0 同口径基线**：三分类同口径 U2 F1 为 U15 **0.577**、U30 **0.503**；旧四类 B0/旧模型数字不得与新 U15/U30 直接比较。B0 的 U1/U3 行为仍是已知弱点，只作基线。
10. **负增益识别**：仅识别原始中位数为负的反相信号；大正偏置下的负增益不可由幅度辨认，需外部增益符号。
11. **Stage 2 事件级只是单尺度原始告警代理**：窗口结束决策保持一个 step、低支撑/未知裁剪，无时间衰减证据/双阈值迟滞/最短持续时间；FA/h 高、PPV 低是预期结果，不能当作 Stage 3 ACTIVE 性能。
12. **Stage 2 RF 只在 VALID 窗训练**：平坦候选（`FLAT_WITH_HISTORY` / `FLAT_EVER_HISTORY`）走 Stage 1 规则路径，不进入 RF；模型不能学习平坦-历史模式，U30 的 VALID U2 训练窗仅 235 个。
13. **Stage 2 最终部署配置用全开发集选择**：权重/校准器/阈值在全开发集 OOF 上选择，只用于保存模型；报告主指标来自外层嵌套 OOF，不把最终配置自评当外部验证。
14. **Stage 3 缺失决策中断**：U15/U30 各 109 处超步长缺口会按预期 deadline 中断并清空证据；U15 事件 F1 因此从 0.257 降至 0.240、FA/h 从 1.710 升至 1.841。PPV 仍低（U15 0.149 / U30 0.182），不能当作可部署性能。
15. **Stage 4 融合负结果**：四尺度融合 F1 0.3527，比最佳单尺度 U60 的 0.3095 高 4.32 个百分点，未达到预先冻结的 +5.0 个百分点门槛；虽然配对 F1 CI 不含 0、FA/h 改善，仍不接入默认路径。长窗 B0 已接近状态机，不能把收益全部归功于融合。鲁棒性/消融数字见第 4 阶段报告；所有数字仅属开发集。

## 7. Stage 1 事实（2026-11-01）

### 7.1 质量状态

- 状态顺序：GAP（失联/长缺口）→ SATURATED → POLARITY_INVALID → QUANTILE_ARTIFACT → NOISY（非零幅度）→ FLAT_* / VALID。
- `q90-q10=0` 不等于完全平坦：有限样本完全相等才是真正常数窗；仍有稀疏脉冲/阶跃/变化（`finite_span>0`）的窗判 `QUANTILE_ARTIFACT`/UNKNOWN，不能成为 U2 候选。
- 真正常数窗在可信历史下仍是 U2 候选；无历史/历史不足仍为 UNKNOWN。
- 平坦且近 300s 有可信呼吸 → `FLAT_WITH_HISTORY`（U2 候选）；
  仅更早有呼吸 → `FLAT_EVER_HISTORY`（低置信 U2 候选）；
  从未有呼吸/历史不足 → `FLAT_NO_HISTORY` / `FLAT_HISTORY_UNKNOWN`（UNKNOWN，不报警）。
- 只有真正常数 `A=0` 不自动弃权：有可信历史时进入 U2 候选；无历史时进入 UNKNOWN，不能当 U0。`QUANTILE_ARTIFACT` 即使有历史也直接 UNKNOWN。
- 非零低幅噪声先过噪声门：`noise_ratio_hf > 0.25` → NOISY/UNKNOWN，不允许被低幅分支短路成 U2 候选。
- 合成验证（见 `report/stage1/quality_state_demo.md`）：真正常数 + 近期历史→U2；
  真正常数无历史→UNKNOWN；稀疏脉冲（q90-q10=0）→QUANTILE_ARTIFACT/UNKNOWN；
  5s 缺口→GAP；削顶→SATURATED；反相→POLARITY_INVALID；高频噪声→NOISY。
- 失联只处理 NaN/长缺口；恒零且无历史为 UNKNOWN，不能与真实呼吸区分；
  饱和需要设备 rail，VitalDB 无 rail，故开发集 SATURATED=0，仅合成验证。
- 负增益识别要求原始波形中位数为负；大正偏置下的负增益无法仅从幅度辨认。
