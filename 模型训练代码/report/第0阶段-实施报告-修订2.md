## A. 本阶段完成项及修改文件

### A.1 四项修订

1. **U2 事件实际读数支撑审计 + 低可信/ignore**
   - `tools/stage0_common.py` 新增：
     - `count_actual_readings`：按原始参考轨道中“连续有效样点段”计数，而不是 1s 网格 ffill 值或每个 100Hz 样点；
     - `split_events_by_support`：可靠（≥2 读）/ 低支撑（<2 读）；
     - `LOW_SUPPORT_READINGS = 2`；
     - 新标签 `ignore_low_support`。
   - `build_events` 返回每个事件的 `support`（`low_readings`/`valid_readings`）。
   - 窗口标签优先级改为：可靠重叠 ≥50% → U2；低支撑重叠 ≥50% → `ignore_low_support`；可靠边界 10–50% → ignore；低支撑边界 10–50% → `ignore_low_support`；其余按 RR。
   - 低支撑事件**不计可靠正例，也不改作负例**；训练/主指标排除，事件级评价单独报告。
   - 冻结划分只用可靠 U2 事件；`case_event_counts.json` 记录每例可靠/低支撑事件及支撑读数。

2. **ACTIVE 匹配增加预冻结有效重叠条件**
   - `tools/event_matching.py`：
     - `MIN_ACTIVE_OVERLAP_SEC = 1.0s`；
     - `MIN_ACTIVE_OVERLAP_FRAC = 0.05`（较短事件时长的 5%）；
     - ACTIVE 候选必须同时满足两个条件；0.1s 擦边不是 TP。
   - 测试：0.1s 重叠 → FP；1.0s 重叠 → TP。

3. **SUSPECT 分 pre-onset / post-onset 评价**
   - `match_suspect` 返回：
     - `pre_onset_matches`：严格早于 onset，报告 lead；
     - `post_onset_matches`：onset 之后、offset 之前，报告**实际 TTD**；
     - `suspect_recall_pre`、`suspect_recall_post`、`median_lead_s`、`median_ttd_s`。
   - 测试：onset 后 5s 提示 → post-onset TTD=5；onset 当秒 → TTD=0；offset 之后 → 不匹配。

4. **规范、统计、测试、hash、报告**
   - 更新四份规范、SSOT、统计脚本、边界测试、host 回归、hash 侧车、修订报告。

## D. 数据统计口径、结果文件和 hash

### D.1 修订后的定义

- U2 事件：`etco2<10`，1s 网格，ffill cap 10s，合并间隔 ≤10s 且间隔无 unknown，最短 10s；先合并后丢弃。
- **实际读数支撑**：事件内原始参考轨道中连续有效 `EtCO2<10` 样点段数；≥2 为可靠，<2 为低支撑（0 读 = 纯 ffill；1 读 = 单次）。
- 窗口标签：可靠重叠 ≥50% → U2；低支撑重叠 ≥50% → `ignore_low_support`；可靠边界 10–50% → ignore；低支撑边界 10–50% → `ignore_low_support`；其余按 RR。
- 质量历史：15s bin、15s 步长；只用 `bin.end_s <= window.start_s`；近 300s / 仅更早 / 从未。
- ACTIVE 匹配：有效重叠 `>=1.0s` 且 `>=5%*min(duration)`；SUSPECT pre/post 分开。

## F. 尚未解决的风险

1. U2 语义仍是“参考 EtCO₂ 低值/缺失样事件”，不是临床确诊屏息。
2. 低支撑事件（174/110）可能是真事件或 ffill 伪迹；当前无法区分，只能 `ignore_low_support` 单列。cap=5 只有 11 个可靠事件/3 例，不能作为主口径。
3. VitalDB 术中机械通气 vs 样机自主呼吸的域偏移未解决。
4. 设备数据不可用；无实时验证；固件无标定 flag/帧序号，实时 C 模式禁用。
5. 质量阈值（A_floor=1.0、300s 近史、15s bin、30s 最短历史）仍暂定；Stage 1 只能在开发集冻结。
6. `FLAT_EVER_HISTORY` 是长屏息/低置信候选，也可能是拔管/断线；不能单独报警。
7. Final Test 可靠 U2 仅 58/32；事件级 CI 会宽，不能报单点精度。
8. ACTIVE 有效重叠阈值（1s/5%）会减少“短促擦边”TP；这是有意预冻结，但 Stage 3/4 必须报告 early/late 比例，不能偷偷放宽。
9. 未训练 U15/U30、未做校准/融合、未做上位机接管；旧固件四分类仍会驱动旧告警。
10. 旧 0.910/0.888 只属于旧 4 类模型，不得用于新 U 模型或未标定设备。
