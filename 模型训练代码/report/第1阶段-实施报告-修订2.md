## A. 本阶段修复项及修改文件

### A.1 两项核心修复

1. **A_ref 只来自“质量合格 + SI 峰≥2”的历史 bin**
   - `si_breathing_bins()` 现在只有 `has_breathing=True` 的 bin 才写有效 A；
     零峰慢漂移段即使 A 很大，也只保留在 `A_raw` 诊断字段中，不进入 A_ref。
   - `HistoryIndex.summary()` 再用 `has_breathing` 掩码取 A 最大值，
     双重保证 A_ref 不包含零峰漂移、GAP、NOISY、饱和或极性错误的 bin。
   - 新增反例：
     - 60s 内一个 15s 慢漂移段（0→200）无 SI 峰；`bins[1]["A"]` 为 NaN，
       `A_raw` 有值，`history.A` 不取该漂移值；
     - 直接构造“高 A 但无呼吸”的 bin 与“低 A 但呼吸”的 bin，历史 A_ref 取后者。

2. **低幅分支不再绕过噪声检查**
   - `classify_signal_state()` 现在在低幅/平坦分支之前先做噪声检查：
     - 非 A=0 且 `noise_ratio_hf > 0.25` → `NOISY`（UNKNOWN）；
     - 只有真正 `A_invalid`（A=0/非有限）才豁免噪声检查。
   - 因此：
     - 非零低幅噪声 → `NOISY`/UNKNOWN，不会变成 `FLAT_WITH_HISTORY` U2 候选；
     - 真正 A=0、且有可信历史 → 仍走 `FLAT_WITH_HISTORY` 候选路径；
     - 真正 A=0、无历史 → `FLAT_NO_HISTORY`/UNKNOWN。
   - 新增反例：
     - `0.01×` 正常波 + 小噪声（A 非零、噪声比 >0.25）→ `NOISY`；
     - 精确 `A=0` 平坦 + 可信历史 → `FLAT_WITH_HISTORY`；
     - 精确 `A=0` 平坦 + 无历史 → UNKNOWN（既有测试继续）。

## F. 尚未解决的风险

1. **B0 性能有限**：15s U2 P 0.455 / R 0.667，30s P 0.345 / R 0.742；U1/U3 召回低。
2. **A_ref 依赖历史质量**：若整段历史都无合格 SI 峰，A_ref 为空，低幅判断只能依赖 A=0/flat_run，未覆盖所有低幅形态。
3. **增益漂移**：A_ref 与当前 A 同尺度可消去固定增益，但病例内增益漂移仍可能影响相对低幅判断。
4. **饱和/失联**：VitalDB 无 rail、无真实拔管；SATURATED/GAP 仅合成或缺失验证；恒零且近期有呼吸仍可能进入候选。
5. **负增益**：只识别原始中位数为负的反相信号；大正偏置下的负增益需外部符号。
6. **弱标签/域偏移**：EtCO₂<10 是设备参考弱标签；VitalDB 术中通气 vs 样机自主呼吸。
7. **Final Test 封存**：未评估，不能据此推断 Final Test 性能。
8. **未上端侧**：15 维 SI 仅 PC/100Hz，未部署 STM32，未做 25Hz。
