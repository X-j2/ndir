## A. 本阶段修复项及修改文件

### A.1 核心修复：常数窗与分位退化伪迹

`A=q90-q10=0` 只说明上下分位相同，并不说明波形完全常数。典型反例：

- 15 秒内 >80% 样本为常数基线；
- 仅含 3 个 0.2 秒稀疏脉冲；
- 此时 `q10=q90=基线`、`A=0`，但 `finite_span=40`，仍存在真实变化。

rev3 在 `normalize_si()` 中新增两个互斥诊断：

```text
finite_span = max(finite samples) - min(finite samples)
constant_flat     = A_invalid and finite_count > 0 and finite_span == 0
quantile_artifact = A_invalid and finite_span > 0
```

- **`constant_flat`**：真正常数窗；有可信历史时保留 U2 候选路径，无历史/历史不足进入 UNKNOWN。
- **`quantile_artifact`**：分位幅度退化但仍含稀疏脉冲/阶跃/其他变化；新增状态
  **`QUANTILE_ARTIFACT`**，进入 UNKNOWN，**不是** U2 候选。
- 判据使用精确 0 比较，不引入绝对幅度门限；正仿射变换下保持。

`classify_signal_state()` 的顺序更新为：

```text
GAP -> SATURATED -> POLARITY_INVALID -> QUANTILE_ARTIFACT
-> NOISY（非 A=0） -> FLAT_* / VALID
```

`si_breathing_bins()` 同时把 `QUANTILE_ARTIFACT` bin 排除出可信历史：
它不贡献 `has_breathing`，也不进入 `A_ref`。

### A.2 新增反例测试

- 稀疏脉冲窗：`A=0`、`constant_flat=False`、`quantile_artifact=True`；
- 稀疏脉冲 + 正常历史：状态 `QUANTILE_ARTIFACT`，规则 UNKNOWN，不是 U2；
- 稀疏脉冲 + 无历史：仍为 `QUANTILE_ARTIFACT`，不是 `FLAT_NO_HISTORY`；
- 稀疏脉冲 bin 不进入 SI 可信历史；
- 真正常数 + 可信历史：仍是 `FLAT_WITH_HISTORY` -> U2；
- 稀疏脉冲的伪迹诊断在正仿射变换下保持；
- 规则层把 `QUANTILE_ARTIFACT` 映射为 UNKNOWN。

## E. 与 rev2 的偏差

| 项 | rev2 | rev3 | 理由 |
|---|---|---|---|
| `A=0` 语义 | 全部视为平坦/候选路径 | **区分真正常数窗与分位退化伪迹** | `q90-q10=0` 仍可能含稀疏脉冲 |
| 新增状态 | 无 | **`QUANTILE_ARTIFACT`** | 伪迹必须 UNKNOWN，不能当呼吸消失 |
| 历史 bin | 排除 GAP/饱和/极性/噪声 | **再排除 `QUANTILE_ARTIFACT`** | 防止伪迹污染 has_breathing/A_ref |
| 质量规范 | v2 | **v3** | 规则语义变更 |
| SSOT | v5 | **v6** | 记录 rev3 |
| 测试数 | 82 | **88** | 新增常数/伪迹反例 |
| 15s 覆盖 | 99.8% | **99.7%** | 伪迹改判 UNKNOWN |
| 30s 覆盖 | 99.9% | **99.7%** | 同上 |
| 15s U2 P/R/F1 | 0.455/0.667/0.541 | **0.448/0.608/0.516** | 保守弃权 |
| 30s U2 P/R/F1 | 0.345/0.742/0.471 | **0.326/0.649/0.434** | 保守弃权 |
| 规则/模型范围 | B0 | B0 | 仍不训练 RF |

**重要：** rev3 的 U2 recall 下降不是模型能力提升，而是把含稀疏脉冲的
伪迹窗从“预测 U2”改为“UNKNOWN”的保守代价。论文/报告必须如实写成
“提高质量判定的可辩护性，牺牲部分召回”，不能写成性能改善。

## F. 尚未解决的风险

1. **B0 性能有限**：15s U2 P 0.448 / R 0.608，30s P 0.326 / R 0.649；U1/U3 召回低。
2. **精确常数判据的边界**：`constant_flat` 要求有限样本完全相等。若真实平坦信号带有量化抖动，会被判为 `QUANTILE_ARTIFACT` 而弃权；这是偏保守的选择，未用绝对容差掩盖。
3. **伪迹只覆盖 A=0**：若稀疏脉冲占比足够大，使 `q90-q10>0`，则不走 `QUANTILE_ARTIFACT`，仍可能通过相对低幅分支成为平坦候选；后续需在开发集上量化。
4. **A_ref 依赖历史质量**：整段历史都无合格 SI 峰时 A_ref 为空，低幅判断只能依赖 A=0/flat_run。
5. **饱和/失联**：VitalDB 无 rail、无真实拔管；SATURATED/GAP 仅合成或缺失验证。
6. **负增益**：只识别原始中位数为负的反相信号；大正偏置下的负增益需外部符号。
7. **弱标签/域偏移**：EtCO₂<10 是设备参考弱标签；VitalDB 术中通气 vs 样机自主呼吸。
8. **Final Test 封存**：未评估，不能据此推断 Final Test 性能。
9. **未上端侧**：15 维 SI 仅 PC/100Hz，未部署 STM32，未做 25Hz。
