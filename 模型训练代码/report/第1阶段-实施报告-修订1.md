## A. 本阶段修复项及修改文件

### A.1 五项修复

1. **Stage 1 因果历史改为质量筛选 + SI 寻峰**
   - 新增 `features/quality_states.py::si_breathing_bins()`：
     - 每个 15s bin 调用 `extract_si_features()`，使用 SI 自适应寻峰；
     - 只有同时满足以下条件的 bin 才是可信呼吸历史：
       1. 非 GAP（NaN 比例 ≤10%、最长缺口 ≤2s）；
       2. 非 SATURATED（提供 rail 时）；
       3. 非 POLARITY_INVALID；
       4. `noise_ratio_hf <= 0.25`；
       5. SI `peak_count >= 2`。
     - NOISY/GAP/饱和/极性错误的 bin 不贡献 `has_breathing`，其 A 也不进入 `A_ref`。
   - 开发集评估脚本已从 Stage 0 的 `breathing_bins` 切换到 `si_breathing_bins`：
     `HistoryIndex(si_breathing_bins(d["co2"]))`。
   - 未来 bin 仍严格排除：只用 `bin.end_s <= window.start_s` 的 bin。

2. **移除固定绝对幅度门限造成的增益依赖**
   - 旧 Stage 1 用 `A < 1.0` 判断平坦；在未知正增益下，`A` 可任意缩放，分类会改变。
   - 新规则：
     ```
     A_invalid = A <= 0 or non-finite
     low_amp = history.A_ref is finite and A < 0.05 * history.A_ref
     flat = A_invalid or flat_run_sec >= 10 or low_amp
     ```
   - `A_invalid` 只表示 A=0/非有限，不再使用 `A<1e-6` 作为分类门限。
   - 低幅判断相对因果历史 `A_ref`，`A_ref` 与当前 A 同乘增益，因此判定在 `x→a*x+b (a>0)` 下不变。
   - 删除运行结果里的 `A<1` / `A<1e-6` 绝对幅度诊断；只保留 `A=0/non-finite` 的尺度无关计数。

3. **skewness 改为三阶标准矩**
   - 原实现为 `mean(z**3)`（未标准化）。
   - 新实现：
     ```
     skewness = mean((z - mean(z))**3) / std(z)**3
     ```
   - 新增测试直接与手工三阶标准矩比较，并验证 0.01× 缩放后不变。

4. **修复模块正常导入**
   - `features/__init__.py` 将仓库 `tools/` 加入 `sys.path`，使
     `features.quality_states` 和 `features.rule_baseline` 可从仓库根直接导入。
   - 新增 subprocess 回归测试：
     `python -c "import features.si_features, features.quality_states, features.rule_baseline"`。

5. **反例回归测试**
   - 新增历史反例：
     - GAP bin 不得成为可信历史；
     - NOISY bin 不得成为可信历史；
     - SATURATED bin 不得成为可信历史；
     - 正常 bin 必须有 SI 峰才成为呼吸历史；
     - 10× 增益 + 偏置下 SI 历史峰数和 `has_breathing` 不变；
     - 0.01× 正常波仍为 VALID（旧 `A<1` 会误判为平坦）；
     - 相对低幅 `0.01×` 正常波在正常历史后为 `FLAT_WITH_HISTORY`；
     - 标准化 skewness 反例；
     - 根目录模块导入。

## F. 尚未解决的风险

1. **B0 仍不是最终方法**：15s U2 P 0.454 / R 0.670，30s U2 P 0.345 / R 0.743；U1/U3 召回低，不能据此宣称系统性能。
2. **A_ref 对增益漂移敏感**：判定用历史 A 最大值；若传感器增益在病例内漂移，相对低幅判据会受影响，需后续用设备数据/漂移仿真验证。
3. **饱和依赖设备 rail**：VitalDB 无 rail，SATURATED 只在合成削顶测试中验证；开发集该状态为 0 不代表设备无饱和。
4. **失联与恒零**：GAP 只识别 NaN/长缺口；拔管后恒零且近期有呼吸仍可能进入 `FLAT_WITH_HISTORY` 候选。
5. **负增益**：只识别原始中位数为负的反相信号；大正偏置下的负增益需外部增益符号。
6. **弱标签**：EtCO₂<10 仍是设备参考弱标签，不能写临床确诊屏息。
7. **域偏移**：VitalDB 术中机械通气 vs 样机自主呼吸；本阶段全部 PC/100Hz。
8. **Final Test 封存**：未评估，不能从本报告推断 Final Test 性能。
