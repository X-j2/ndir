## A. 完成项

### A.1 `compare_host` 显式失败判定

`tools/stage4_host_reference.py` 的 `compare_host()` 现在对四个尺度和融合
分别输出并判定：

- 决策/融合帧数量：`n_host`、`n_reference`、`frame_count_diff`、
  `frame_count_equal`；
- 概率 `None`：单侧 `None` 计入 `p_none_mismatch`，双方均 `None` 不算差异；
- 非有限值：特征与概率分别统计 host/reference 的 `NaN/Inf`；
- 超容差：特征与概率容差均冻结为 **1e-9**，超过计入
  `*_tolerance_exceeded`；
- 事件转换：各尺度与融合逐条比较 `kind`、`time`、`episode_id`，输出
  `transition_host`、`transition_reference`、`transition_mismatch`、
  `transition_equal`；
- 融合帧时间/质量：`time_mismatch`、`quality_mismatch` 与汇总的
  `frame_mismatch` 均纳入 `_record_status()` 失败汇总；
- 顶层 `ok` 与 `failure_reasons` 汇总所有失败项。

为读取尺度/融合事件转换，上位机 `Stage4Runtime` 新增只读
`scale_transitions(scale)` 和 `fusion_transitions()`，不改变运行时逻辑。

### A.2 测试断言

`test_stage4_host.py` 的四尺度独立参考测试现在必须断言：

- 四个尺度与融合的帧数相等，`frame_count_diff == 0`；
- 概率 `None` 不一致、非有限值、超容差均为 0；
- 概率最大绝对误差 ≤ **1e-9**；
- 各尺度和融合的每条事件转换 `kind`、`time`（9 位小数）、`episode_id`
  与独立参考一致；
- 顶层 `comp["ok"]` 为真。

### A.3 故障注入回归

新增测试覆盖并全部要求 `compare_host()` 判失败：

| 注入故障 | 断言 |
|---|---|
| 删除一条融合帧 | `FUSION.frame_count`，帧数差非零 |
| 概率偏移 0.2（U15 + 融合） | `p_tolerance_exceeded` |
| 单侧概率改为 `None`（U15 + 融合） | `p_none_mismatch` |
| 概率/特征放入 `NaN/Inf` | `p_nonfinite_reference` / `feature_nonfinite_reference` |
| U15/U30/U60/U90/FUSION 的 `kind`、`time`、`episode_id` 分别篡改 | 对应 `transition_mismatch` |
| 融合帧时间 +0.5 s | `FUSION.time_mismatch`，顶层 `ok=False`，退出码 1 |
| 融合帧质量改为错误值 | `FUSION.quality_mismatch`，顶层 `ok=False`，退出码 1 |
